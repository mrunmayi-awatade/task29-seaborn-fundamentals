# Task 29 - Seaborn Fundamentals

## Overview
This task demonstrates data visualization using Seaborn and Matplotlib in Python.

## Topics Covered
- Importing Pandas, Matplotlib, and Seaborn
- Creating a sample employee dataset
- Creating count plots
- Creating box plots
- Creating scatter plots
- Creating histograms
- Creating violin plots
- Creating heatmaps and correlation matrices
- Comparing Seaborn and Matplotlib
- Customizing plot styles
- Creating pair plots
- Saving charts as image files

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files Included
- `task29_seaborn_fundamentals.ipynb`
- `seaborn_barplot.png` (optional)

## Outcome
Learned how to create and customize statistical visualizations using Seaborn and compare them with Matplotlib.
